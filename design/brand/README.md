# 小程序名称与头像

## 名称

| 方案 | 名称 | 说明 |
|---|---|---|
| **推荐** | **SMP学术动态** | 简称加功能，短、好记、可搜索，与公众号栏目“委员学术动态”呼应 |
| 备选 | SMP委员动态 | 更强调“委员”，面向内部编辑时更直观 |
| 备选 | 社媒处理学术速递 | 不含英文简称，适合名称冲突时使用 |
| 备选 | SMP学术观察 | 偏媒体感，适合以后对外开放阅读 |

**简介**（4~120 字）：中国中文信息学会社会媒体处理专委会（SMP）委员学术动态的采集、复核与发布工具，每周/每月生成学术动态简报。

**服务类目**：工具 > 信息查询，或 教育 > 教育信息服务。以注册时平台的可选项为准。

**注册注意**：以微信公众平台最新规则为准。
- 小程序名称长度 4~30 个字符，一个中文字算 2 个字符。
- 名称在全平台唯一，需要先在注册页检索是否被占用。
- 名称含“SMP”、“社会媒体处理专委会”等机构标识时，注册主体应为学会，或其挂靠单位并提供授权材料，否则审核可能不通过。

## 头像

推荐**方案 A：学者网络气泡**（`avatar-A-1024.png`）：
- **寓意**：对话气泡代表社会媒体，节点连线代表委员组成的学术网络。
- **配色**：系统蓝到靛蓝的渐变，与小程序界面一致。
- **构图**：图形在圆形安全区内，微信以圆形展示时不会被裁掉；40/28/20px 小尺寸下仍可辨认。

| 文件 | 用途 |
|---|---|
| `avatar-A-1024.png` | 上传到公众平台“小程序头像”（方形原图，平台自动圆形显示） |
| `avatar-A-144.png` | 小尺寸预览 |
| `avatar-B/C-*.png` | 备选：SMP 字标 / 传播信号 |
| `brand-board.png` | 三个方案在圆形裁切、小尺寸和真实场景下的对比 |
