# 小程序名称与头像

## 名称

| 方案 | 名称 | 说明 |
|---|---|---|
| **推荐** | **SMP学术动态** | 简称加功能，短、好记、可搜索，与公众号栏目“委员学术动态”呼应 |
| 备选 | SMP委员动态 | 更强调“委员”，面向内部编辑时更直观 |
| 备选 | 社媒处理学术速递 | 不含英文简称，适合名称冲突时使用 |
| 备选 | SMP学术观察 | 偏媒体感，适合以后对外开放阅读 |

**简介**（4~120 字）：中国中文信息学会社会媒体处理专委会（SMP）委员学术动态的采集、复核与发布工具，每周/每月生成学术动态简报。

**服务类目**：工具 > 信息查询，或 教育 > 教育信息服务。以注册时平台的可选项为准。

**注册注意**：以微信公众平台最新规则为准。
- 小程序名称长度 4~30 个字符，一个中文字算 2 个字符。
- 名称在全平台唯一，需要先在注册页检索是否被占用。
- 名称含“SMP”、“社会媒体处理专委会”等机构标识时，注册主体应为学会，或其挂靠单位并提供授权材料，否则审核可能不通过。

## 头像（SMP × 社交动态讯号，JPG）

| 方案 | 文件 | 说明 |
|---|---|---|
| **1 推荐** | `avatar-1-1024.jpg` | SMP 字标居中，右上方三道扩散讯号弧，黄色亮点为“动态”源；小尺寸下字标和讯号都清晰 |
| 2 | `avatar-2-1024.jpg` | 对话气泡内嵌 SMP，气泡右上角发出讯号，社交属性最直观 |
| 3 | `avatar-3-1024.jpg` | SMP 字标 + 上方学者网络节点连线，末端节点发出讯号 |

- 每个方案都提供 1024 / 512 / 144 三种尺寸的 JPG。上传到公众平台时用 1024 版本，平台会自动圆形显示。
- 构图都在圆形安全区内；配色为系统蓝到靛蓝渐变，与小程序界面一致。
- `brand-board.jpg` 是三个方案在原图、圆形裁切、40/28/20px 小尺寸和搜索结果场景下的对比。
